The Desk
Full screen set · light + dark
Every project opens onto a hub. The editor takes the whole screen with no permanent chrome, and the binder swipes in from the left edge so scene-to-scene movement never routes back through the hub. Everything else is a tile you go into and come back out of.
One gesture to learn. Left-edge swipe opens the binder, anywhere in the editor. Nothing else is hidden behind a gesture.
Hub is per-project. The project switcher lives in the hub header, so changing books is one tap, not a trip back up the stack.
Capture reaches out. The hub bar, plus a share-sheet target so a thought caught in another app lands in the inbox.
